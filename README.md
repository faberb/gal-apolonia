# Gal Apolonia — preview

A responsive, static redesign of the archived Gal Apolonia travel journal. The page brings the original Mount Fuji hike report and a small set of its photographs into a lightweight, dependency-free preview.

## View locally

Open `index.html` in a browser. No build step, framework, or server is required.

## Contents

- `index.html` — one-page editorial site and restored Mt. Fuji story
- `styles.css` — responsive layout and visual system
- `script.js` — accessible mobile navigation
- `assets/` — six resized photos from the archived WordPress uploads

The original WordPress files, database exports, configuration, logs, and unrelated media are intentionally not part of this preview.
